# math

Generative mathematical expression art rendered to canvas.

Open `index.html` in a browser (or serve the directory) to generate random math expressions visualized as pixel art.

- Expressions can be integer or floating-point.
- Outputs include greyscale and color-ramped versions with overlaid equation text.
- Click an image to download the PNG.

Built with OCaml compiled to JavaScript via js_of_ocaml.
